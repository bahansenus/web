Tier 1 — Priority Targets (Must-Read)

1. Shai-Hulud npm Supply Chain Worm Compromises 1,280+ Packages via GitHub Actions Pipelines

Source & Article Link: HackRead / TLDR InfoSec

Technical Severity / Domain: Software Supply Chain Security / Critical (Self-Propagating Worm)

Why You Must Read This: A new Shai-Hulud worm variant compromised over 1,280 npm packages (including Keyv) by injecting malicious commits into GitHub Actions build pipelines. The worm uses a preinstall hook to download Bun and execute an obfuscated loader that aggressively harvests AWS credentials, Kubernetes tokens, HashiCorp Vault secrets, npm tokens, and SSH keys from developer machines and CI runners.

Recommended Immediate Action: Rotate all developer and cloud tokens immediately if any compromised dependency versions were pulled, and perform manual log reviews rather than relying solely on scheduled vulnerability scans.

2. Over 4,400 Rockwell PLCs Exposed Online; 22 Found in Targeted Water Utility Cities

Source & Article Link: The Hacker News / TLDR InfoSec

Technical Severity / Domain: Industrial Control Systems (ICS/SCADA) / Critical Infrastructure Risk

Why You Must Read This: Forescout identified over 4,400 internet-facing Rockwell Automation PLCs globally, including 22 located in US water utility cities recently subjected to cyberattacks. Attackers compromised controllers via open Ethernet/IP port 44818 without exploiting complex zero-days, locking operators out by altering logic configurations.

Recommended Immediate Action: Immediately disconnect all industrial controllers from direct public internet exposure behind perimeter firewalls or industrial VPNs, and apply Rockwell Advisory SD1790 to clear unauthorized locks.

3. Pre-Auth Stack Buffer Overflow on Mercusys MB115-4G Router (CVE-2026-12495)

Source & Article Link: Rotcee Hardware Research / TLDR InfoSec

Technical Severity / Domain: Hardware & Firmware Security / Critical (CVE-2026-12495)

Why You Must Read This: Hardware reverse engineering of Amazon Spain's best-selling router identified a pre-authentication vulnerability in /usr/bin/httpd. The http_gdpr_decrypt function copies up to 2,048 bytes of AES-decrypted, attacker-controlled data into a 512-byte caller stack buffer with no bounds check. Static analysis in Ghidra and Ghidriff confirmed the flaw persisted unpatched across firmware versions v1.7.0 through v1.9.0.

Recommended Immediate Action: Upgrade Mercusys MB115-4G router units to firmware v1.11.0 or newer, which adds bounds checking, HMAC verification, and transitions login decryption from RSA to ECC.

4. Greatness Phishing Service Spoofs RingCentral to Steal M365 Session Tokens

Source & Article Link: TLDR InfoSec — Greatness RingCentral Phish

Technical Severity / Domain: Cloud IAM & Phishing / High

Why You Must Read This: The Greatness phishing platform bypassed email gateway filters by spoofing RingCentral voicemail alerts to target organizations that had blanket-whitelisted the domain, despite failing SPF, DKIM, and DMARC checks. Once clicked, victims were routed through Adversary-in-the-Middle (AiTM) proxies to steal MFA tokens, enabling stealth data exfiltration across Microsoft 365.

Recommended Immediate Action: Replace broad safe-sender exclusions with strict authentication enforcement, hunt for anomalous MFA sign-ins originating from hosting providers, and revoke active user tokens upon suspected exposure.

1. Cloudflare Open-Sources pvcli Privacy Proxy Debugger

Domain: Cloud Security & Privacy Engineering

Subject / Topic Summary: Cloudflare open-sourced pvcli, a CLI utility designed to simplify debugging Oblivious HTTP (OHTTP) privacy proxies by automating binary encoding, encryption, and multi-party request routing in a single command.

Key Technical Takeaways:

Replaces manual hex-encoded key parsing with verbose step-by-step logging across client, relay, and gateway hops.

Supports mTLS to relays and custom relay headers, with a roadmap including MASQUE transports and post-quantum OHTTP.

Essential Direct Quote: "pvcli simplifies debugging privacy-preserving protocols like Oblivious HTTP by handling the binary encoding, encryption, and multi-party request routing in a single curl-style command."
