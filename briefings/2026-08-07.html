Daily Security Intelligence Briefing — August 7, 2026

Overall Daily Threat Level: HIGH. Primary threat vectors include a major resurgence of the self-propagating Shai-Hulud / ChainDrop npm supply-chain worm poisoning over 1,280 packages, an Open VSX extension campaign harvesting developer environment metadata across 77 extension packages, and a pre-auth stack buffer overflow in Mercusys routers (CVE-2026-12495). On the telecom and SOC architecture fronts, NIST published CSWP 36F for 5G Initial NAS message encryption, and DNB Cyber Defense Center detailed agentic incident response playbooks built on reactive Python notebooks.

Tier 1 — Priority Targets (Must-Read)

1. Shai-Hulud / ChainDrop npm Worm Resurges, Poisoning 1,280+ Packages via CI Pipelines

Source & Article Link: HackRead / TLDR InfoSec / Microsoft Security Blog

Technical Severity / Domain: Software Supply Chain Security / Critical (Self-Propagating Worm)

Why You Must Read This: A new variant of the self-propagating Shai-Hulud (ChainDrop) worm has compromised over 1,280 npm packages, including the popular Keyv library. The worm infects package manifests via hijacked GitHub Actions pipeline tokens. A preinstall hook executes Bun to run an obfuscated loader that aggressively harvests AWS credentials, Kubernetes tokens, HashiCorp Vault secrets, npm tokens, and SSH keys from developer workstations and CI runners. The stolen publishing tokens are immediately reused to infect and publish dependent packages automatically.

Recommended Immediate Action: Audit all node dependencies for compromised versions, immediately rotate all CI/CD, AWS, Kubernetes, and Vault credentials on affected systems, and perform manual log audits rather than relying solely on automated vulnerability scanners.

2. 77 Open VSX Extensions Found Exfiltrating Developer Workstation Telemetry

Source & Article Link: TLDR InfoSec — Open VSX Campaign / Manifold Security

Technical Severity / Domain: Application Security & Developer Tooling / High

Why You Must Read This: Manifold Security uncovered an "evil twin" campaign on the Open VSX extension registry where 77 malicious extensions impersonated legitimate VS Code plugins. While claiming to collect anonymous usage metrics, the extensions exfiltrated OS usernames, workspace file paths, Git commit hashes, and CI/CD environment variables to mangorbit[.]com. The C2 infrastructure utilized DNS TXT record lookups to bypass standard web proxy logging.

Recommended Immediate Action: Block domain mangorbit[.]com at perimeter DNS/firewalls, audit VS Code and Open VSX extension IDs across developer workstations, and restrict extension installation to approved internal registries.

3. Hardware Hacking: Pre-Auth Stack Buffer Overflow on Mercusys MB115-4G Router (CVE-2026-12495)

Source & Article Link: Rotcee Hardware Research / TLDR InfoSec

Technical Severity / Domain: Embedded & Firmware Security / Critical (Pre-Auth RCE)

Why You Must Read This: Hardware reverse engineering of the Mercusys MB115-4G router identified a pre-authentication vulnerability in /usr/bin/httpd. The http_gdpr_decrypt function copies up to 2,048 bytes of AES-decrypted, attacker-controlled data into a 512-byte stack buffer without bounds checking. Static analysis in Ghidra and Ghidriff confirmed the vulnerability persisted unpatched across firmware versions v1.7.0 through v1.9.0.

Recommended Immediate Action: Upgrade Mercusys MB115-4G routers to firmware v1.11.0 or newer, which adds caller buffer bounds checking, HMAC verification, and transitions login decryption from RSA to ECC.

4. NIST Releases Draft CSWP 36F: 5G Initial Non-Access Stratum (NAS) Message Security

Source & Article Link: NIST NCCoE 5G White Paper

Technical Severity / Domain: Telecom & Wireless Infrastructure Security / Architectural Guidance

Why You Must Read This: NIST's National Cybersecurity Center of Excellence (NCCoE) released draft Cybersecurity White Paper (CSWP) 36F (Initial Non-Access Stratum Message Security). Unlike 4G networks where the initial connection handshake between device and core network (Initial NAS Message) was transmitted in cleartext—leaving devices exposed to IMSI catchers and MitM attacks—5G specifications enable end-to-end encryption and integrity protection for initial NAS payloads.

Recommended Immediate Action: Mobile network operators and 5G enterprise architects should review CSWP 36F guidelines to verify NAS encryption configurations on 5G standalone (SA) cores; public comments close September 7, 2026.

Tier 2 — Essential Intelligence (Summaries & Analysis)

1. Greatness Phishing Service Spoofs RingCentral for M365 Account Hijacking

Domain: Cloud Security & BEC Defense

Subject / Topic Summary: The Greatness phishing-as-a-service platform bypassed Exchange Online email filters by forging RingCentral voicemail alerts to target organizations that had blanket-whitelisted RingCentral domains. Clicking the lure routed victims through an adversary-in-the-middle (AiTM) proxy to capture MFA-approved session tokens, allowing attackers to replay tokens from VPN endpoints and silently siphon Microsoft 365 data.

Key Technical & Strategic Takeaways:

Demonstrates that domain-level safe-sender whitelists undermine SPF/DKIM/DMARC authentication and create major exposure gaps.

Remediation: Remove blanket domain whitelists, enforce Conditional Access device posture/location checks, and revoke active sessions for compromised users.

Essential Direct Quote: "The Greatness phishing platform recently bypassed email filters by spoofing RingCentral voicemail alerts to target organizations that had blanket-whitelisted the domain... routing victims through an adversary-in-the-middle flow to steal MFA-approved tokens."

Source: TLDR InfoSec — RingCentral Phish
