Daily Security Intelligence Briefing — July 30, 2026

Overall Daily Threat Level: HIGH. Primary threat vectors include HollowGraph M365 Calendar Invite Command-and-Control, active malvertising campaigns deploying FakeAgent SectopRAT via claude.ai artifact redirects, and widespread IPMI/BMC password cracking across 24,000+ data center management interfaces (CVE-2013-4786). On the architecture front, MCP released a major stateless protocol update (2026-07-28), while security leaders advocate moving from Zero Trust to "Zero Custody" architectures for autonomous AI agent workflows.

Tier 1 — Priority Targets (Must-Read)

1. FakeAgent Campaign Uses Claude.ai Artifact Redirects to Deploy SectopRAT

Source & Article Link: Huntress Threat Research / TLDR InfoSec

Technical Severity / Domain: Application & Endpoint Security / High-Critical (29 Organizations Impacted)

Why You Must Read This: Sponsored Bing search ads for "claude desktop app" redirected victims to a genuine claude.ai user-generated artifact URL. The artifact contained JavaScript that forwarded users through claude.ai.download-app[.]us to download a malicious ClaudeDesktop.exe. The executable was actually JetBrains jcef_helper.exe DLL-sideloading a tampered libcef.dll (VMProtect packed) that pulled a .NET SectopRAT payload via EtherHiding from an Ethereum BSC smart contract. A secondary persistence mechanism dropped signed IBM SPSS binaries (sslconf.exe) alongside a malicious tempdir.dll that executed DirectX shader-based AES-256 decryption to defeat sandbox analysis.

Recommended Immediate Action: Block C2 IP 2.24.131[.]246 and BSC contracts; hunt for ClaudeDesktop.exe writes, scheduled tasks under %APPDATA%\Roaming\Microsoft\EdgeUpdate\Install, and Defender exclusions added around software installers. Treat vendor artifact landing pages as untrusted download sources.

2. 24,000+ Data Center IPMI/BMC Hosts Exposed to Offline Password Cracking

Source & Article Link: Lava Research / TLDR InfoSec

Technical Severity / Domain: Infrastructure & Hardware Security / Critical (CVE-2013-4786)

Why You Must Read This: Internet scanning of UDP port 623 revealed 36,872 exposed Baseboard Management Controller (BMC) interfaces, with 24,650 returning password-derived HMAC-SHA1 hashes during RAKP authentication without requiring successful login. Supermicro factory 10-character passwords (26^10 keyspace) were cracked offline in ~1 hour on an 8-GPU rig, while HPE iLO 8-character hashes were cracked in ~32 seconds. Active exploitation is confirmed, including iLO 4 management consoles defaced with 0.3 BTC ransom demands.

Recommended Immediate Action: Block UDP port 623 at network perimeters, rotate all factory BMC/iLO passwords immediately, disable IPMI 1.5 and Cipher Suite 0/NONE, and restrict management interfaces to an isolated VLAN or VPN.

3. HollowGraph Malware Uses Microsoft 365 Calendar Invites for Covert C2

Source & Article Link: Patrick Duggan Research / Unsupervised Learning

Technical Severity / Domain: Cloud Security & Threat Hunting / High (Graph API C2)

Why You Must Read This: HollowGraph malware infected 12 enterprise systems and established command-and-control entirely inside Microsoft 365 using calendar invites as the payload transport channel. Because the communication relies on legitimate M365 infrastructure and API calls, traditional network perimeter firewalls and IP blocklists cannot detect or block the C2 traffic.

Recommended Immediate Action: Implement Graph API behavioral logging and audit for unusual calendar event creations or automated attendee updates originating from internal service accounts.

Tier 2 — Essential Intelligence (Summaries & Analysis)

1. From Zero Trust to "Zero Custody" for Autonomous AI Agents

Domain: AI & Cloud Security Architecture

Subject / Topic Summary: Security analysis argues that Zero Trust model validation is insufficient for AI agents because identity verification cannot prevent prompt injection or in-context hijacking. The proposed "Zero Custody" architecture dictates that agent reasoning loops must hold no secrets or high-privilege credentials directly; instead, external API brokers and security gateways inject tokens and re-identify data only after verifying policy constraints.

Key Technical & Strategic Takeaways:

AI reasoning environments should be treated as ephemeral, untrusted compute spaces.

Credentials, API keys, and raw sensitive data must remain isolated in external broker gateways.

Essential Direct Quote: "Zero Trust is insufficient for AI agents because verifying identity does not stop attackers from hijacking behavior through malicious language in context. Zero Custody holds that the reasoning loop should hold nothing that matters, so a compromised agent has empty hands."

Source: 2am Security / TLDR IT

3. Distributed npm Package Cluster Delivers Cross-Platform RAT to Alibaba Developers

Domain: Supply Chain Security & Malware Analysis

Subject / Topic Summary: Socket discovered an 18-package npm typosquatting cluster impersonating Alibaba's @ali scope (smart-config-manager, cloud-config-fetcher, local-config-parser). The packages split loader logic across dependencies and escaped the Node.js VM sandbox via items.constructor.constructor to drop aone-cli, a cross-platform RAT supporting DingTalk lateral movement, file transfer, and encrypted reverse TCP proxying.

Key Technical & Strategic Takeaways:

Persistence achieved via ~/.zshrc entries, 10-minute macOS Launch Agents, trojanized app.asar files, and Linux /tmp binaries.

Remediation: Treat impacted systems as fully compromised, rotate credentials from clean hardware, and audit for suspicious npm dependencies in internal builds.

Essential Direct Quote: "Socket uncovered a three-month stealth campaign involving 18 npm packages that split loader functions across dependencies... escaping the Node.js vm sandbox via items.constructor.constructor to stage a cross-platform RAT."
