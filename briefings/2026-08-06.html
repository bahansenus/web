Daily Security Intelligence Briefing — August 6, 2026

Overall Daily Threat Level: CRITICAL. Primary threat vectors include a zero-day pre-authentication root execution flaw in macOS screensharingd, CISA's emergency order mandating immediate patching of an actively exploited N-able N-central "God mode" RMM vulnerability, and 17 security advisories across self-hosted n8n instances including MCP schema path traversal RCE. Additionally, Cloudflare open-sourced Cloudflare OS for agentic sandboxing, while Google Cloud launched serverless model routing on API Gateway.

Tier 1 — Priority Targets (Must-Read)

1. macOS Pre-Auth screensharingd Bug Yields Root Access in Under 60 Seconds

Source & Article Link: CyberKendra / TLDR InfoSec

Technical Severity / Domain: Operating System Security & Remote Execution / Critical (Unauthenticated Zero-Day RCE)

Why You Must Read This: A critical pre-authentication vulnerability in macOS screensharingd (versions <=26.5) allows unauthenticated network attackers to achieve arbitrary root execution in under 60 seconds. By transmitting oversized frames, the daemon encounters a buffer state flaw that triggers a stale success code, completely bypassing password checks and encryption handshakes.

Recommended Immediate Action: Upgrade macOS workstations to version 26.6 immediately; if updates are delayed, disable Screen Sharing in System Settings and ensure System Integrity Protection (SIP) remains enabled.

2. CISA Issues Emergency Directive for Actively Exploited N-able N-central "God Mode" Flaw

Source & Article Link: The Register / TLDR IT

Technical Severity / Domain: Cloud Security & MSP Infrastructure / Critical (Active Exploitation)

Why You Must Read This: CISA ordered federal agencies to patch an actively exploited authentication bypass in N-able N-central remote monitoring and management (RMM) platform within three days. Attackers exploiting the vulnerability gain full administrative access to MSP management consoles, deploying persistent Cloudflare Tunnels into managed customer environments and executing downstream supply-chain compromises.

Recommended Immediate Action: Upgrade self-hosted N-able N-central instances to version 2026.3.1.7 or later immediately, and hunt for unauthorized Cloudflare Tunnel processes or new administrative user creations.

3. n8n Patches 17 Vulnerabilities Including MCP Schema Path Traversal RCE & Sandbox Escapes

Source & Article Link: n8n Security Advisory / n8n Security Update Email

Technical Severity / Domain: Automation Platform & AI Security / High-Critical (GHSA-6h4x-896x-fw5m, GHSA-m3hg-p5r9-fg9h)

Why You Must Read This: n8n published a bi-weekly security update detailing 17 vulnerabilities across self-hosted automation workflows. Highlights include an RCE in the main n8n process via path traversal in MCP Node-Schema loading (GHSA-6h4x-896x-fw5m), JavaScript Task Runner VM sandbox escape via EventEmitter prototype pollution (GHSA-m3hg-p5r9-fg9h), and code execution in the Git node via unchecked repository-local git configurations (GHSA-m87g-qr43-ccvc).

Recommended Immediate Action: Upgrade self-hosted n8n deployments to patched release versions v1.123.69 (v1 train), v2.33.4 (v2 stable), or v2.34.1 (v2 beta).

4. Gitea 1.27.1 Fixes Unauthenticated File Read & Diffpatch Git Hook RCE

Source & Article Link: Gitea Official Release Notes / TLDR InfoSec

Technical Severity / Domain: Application Security & DevSecOps / Critical (CVE-2026-59774, CVE-2026-60004)

Why You Must Read This: Gitea 1.27.1 resolved two critical unauthenticated flaws affecting versions 1.22.1 through 1.27.0: CVE-2026-59774 (arbitrary file read via Org-mode #+INCLUDE directives) and CVE-2026-60004 (remote code execution via diffpatch API malicious Git hook installation). Neither bug requires authentication or user interaction.

Recommended Immediate Action: Upgrade self-hosted Gitea servers to version 1.27.1 immediately.

3. RedLotus: Rust-Based Windows UEFI Bootkit

Domain: Systems Security & Kernel Evasion

Subject / Topic Summary: Research paper released RedLotus, an educational Rust UEFI bootkit. RedLotus hooks the early boot sequence to map unsigned kernel payloads before Windows Driver Signature Enforcement (DSE) initializes, establishing usermode-to-kernel IPC via HalDispatchTable pointer overwrites.

Key Technical & Strategic Takeaways:

Demonstrates low-level Rust bootkit tradecraft; completely neutralized on systems enforcing Hypervisor-Protected Code Integrity (HVCI).

Essential Direct Quote: "RedLotus is an educational, Rust-based UEFI bootkit that bypasses Driver Signature Enforcement by hooking the early boot sequence... reliance on noisy RWX allocations makes it detectable by modern EDRs and neutralized if HVCI is enabled."

Source: RedLotus Research / TLDR InfoSec

4. Amazon Attributes Supply-Chain Campaign to DPRK Actor SAPPHIRE SLEET

Domain: Threat Intelligence & Supply Chain Security

Subject / Topic Summary: Amazon Threat Intelligence formally attributed long-running malicious packages in NPM (axios, debug, chalk) to North Korean state-sponsored actor SAPPHIRE SLEET. The campaign used fragmented package dependencies, runtime payload fetching, and sandbox-aware detonation.

Key Technical & Strategic Takeaways:

Adversaries are using generative AI to generate hallucinated dependency names for typosquatting attacks.

Essential Direct Quote: "Amazon Threat Intelligence attributed the compromises of major NPM packages to DPRK-linked actor SAPPHIRE SLEET... noting that generative AI is accelerating these threats through hallucinated dependencies."

Source: Amazon Security Blog / TLDR InfoSec
